# LLM Inference Performance Lab

Hands-on exploration of LLM inference systems, GPU performance, serving, benchmarking, KV cache, batching, quantization, CUDA profiling, and optimization.

## Goal

Learn production LLM inference engineering by building experiments, measuring behavior, explaining results, and documenting findings.

## Learning rule

The code in the experiments is written manually. AI may review, explain, and debug, but should not replace the learning process by generating finished experiment implementations.
